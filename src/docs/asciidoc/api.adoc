프리모아 공고 수집 API 문서. 이 문서의 요청·응답 예시는 `CrawlControllerDocsTest` 가 실제로 호출한 결과로 만들어진다.
테스트가 실패하면 문서도 만들어지지 않는다.

[[overview]]
== 개요

|===
| 종류 | API | 응답

| 수동 수집 | `POST /api/crawl` | 끝날 때까지 기다림 (200)
| 전체 수집 | `POST /api/crawl/all` | 접수만 하고 runId 즉시 응답 (202)
| 진행 상황 | `GET /api/crawl/runs/{runId}` | 수집 이력 1건 (200 / 404)
| 증분 수집 | `POST /api/crawl/incremental` | 새 공고가 끊길 때까지 수집 (200)
|===

오류 응답은 `{"error": "메시지"}` 형식이다.

|===
| 상태 코드 | 의미

| 400 | 요청 값이 잘못됨 (예: maxPages 범위 초과)
| 409 | 다른 수집이 실행 중
| 502 | 프리모아 요청 실패
|===
